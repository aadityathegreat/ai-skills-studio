Source / Method / Limitations

Know what you’re comparing

This is life expectancy at birth, total (years), World Bank indicator SP.DYN.LE00.IN, from World Development Indicators. It estimates how long a newborn would live if the period’s mortality patterns persisted. It is a population estimate, not a prediction for an individual.

Differences and time trends are descriptive. These charts do not establish causes. Country estimation methods and registration coverage can differ; historical estimates can be revised. The selected countries are a chosen comparison group, not the world.

Coverage and validation

Numeric source values are retained at full precision; display uses two decimals. Changes and gaps are calculated before rounding. No interpolation, extrapolation, population weighting or smoothing. Missing countries are excluded from ranks; the denominator is shown. A comparison-year value is never substituted from a different year.
